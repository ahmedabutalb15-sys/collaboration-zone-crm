# Collaboration Zone CRM

نسخة أولى جاهزة للتشغيل محليًا ومصممة للموبايل والكمبيوتر.

## المتطلبات
- Windows
- Node.js 20 أو أحدث

## التشغيل
1. ثبّت Node.js من الموقع الرسمي: https://nodejs.org/
2. فك ضغط المشروع.
3. افتح CMD داخل مجلد المشروع.
4. نفّذ:
   npm install
   npm start
5. افتح المتصفح على:
   http://localhost:3000

## الدخول الأول
Username: admin
Password: admin123

**غيّر كلمة المرور لاحقًا** (هذه النسخة الأولية لا تحتوي شاشة تغيير كلمة المرور بعد).

## إضافة الموظفين
ادخل Admin > الموظفين والحسابات > أنشئ حساب لكل موظف.
يمكنك إعطاء الموظف Employee أو Manager أو Admin.

## تشغيله على أجهزة الشركة
للتجربة على نفس الجهاز استخدم localhost.
لربطه بـ 6 أجهزة داخل نفس الشبكة، شغّل السيرفر على جهاز ثابت واستخدم عنوانه الداخلي مثل:
http://192.168.1.20:3000
ويجب السماح لـ Node.js عبر Windows Firewall.

## الموبايل
من Chrome/Safari افتح عنوان النظام، ثم اختر Add to Home Screen / إضافة إلى الشاشة الرئيسية.
سيظهر كأنه تطبيق PWA.

## ملاحظات مهمة
- قاعدة البيانات محفوظة في crm.sqlite داخل المشروع.
- المرفقات داخل uploads.
- خذ Backup دوريًا لملفي crm.sqlite ومجلد uploads.
- هذه نسخة MVP داخلية؛ قبل استخدامها في بيئة إنتاج عامة يُفضّل إضافة SSL، تغيير session secret، تغيير كلمة مرور admin، ونسخ احتياطي آلي.

## المزايا الموجودة
- Login وحسابات متعددة
- Roles: Employee / Manager / Admin
- Dashboard
- Daily Reports مع مرفقات
- اعتماد/رفض الريبورتات
- Tasks
- Clients
- إدارة المستخدمين
- تصدير الريبورتات CSV الذي يفتح في Excel
- Responsive/PWA للموبايل
